🛠️ Crear Trace con T-SQL

-- 1. CREAR EL TRACE
DECLARE @TraceID INT;
EXEC sp_trace_create 
    @traceid = @TraceID OUTPUT,
    @options = 2,                            -- Rollover de archivos
    @tracefile = N'C:\Temp\MiTrace',         -- Sin extensión .trc
    @maxfilesize = 100;                      -- 100 MB por archivo

-- 2. AGREGAR EVENTOS Y COLUMNAS
-- Evento SQL:BatchCompleted (12) con columna Duration (13)
EXEC sp_trace_setevent @TraceID, 12, 13, 1;  -- Duration
EXEC sp_trace_setevent @TraceID, 12, 1, 1;   -- TextData
EXEC sp_trace_setevent @TraceID, 12, 16, 1;  -- Reads

-- 3. AGREGAR FILTROS
-- Solo consultas > 1 segundo (1,000,000 microsegundos)
EXEC sp_trace_setfilter @TraceID, 13, 0, 4, 1000000;

-- 4. INICIAR
EXEC sp_trace_setstatus @TraceID, 1;         -- 1 = Iniciar

-- 5. DETENER Y CERRAR
EXEC sp_trace_setstatus @TraceID, 0;         -- 0 = Detener
EXEC sp_trace_setstatus @TraceID, 2;         -- 2 = Cerrar

-- 6. LEER ARCHIVO
SELECT * FROM fn_trace_gettable(N'C:\Temp\MiTrace.trc', DEFAULT);

🔍 Filtros para Reducir el Ruido

CompOp Significado Ejemplo de Uso
0 = (igual) Solo una base de datos específica
4 >= (mayor o igual) Duration >= 1000000 (queries > 1 seg)
7 NOT LIKE Excluir SQL Profiler de la captura 
-- Filtrar solo base de datos BancoDB
DECLARE @DBID INT = DB_ID('BancoDB');
EXEC sp_trace_setfilter @TraceID, 3, 0, 0, @DBID;

-- Filtrar consultas > 500ms
EXEC sp_trace_setfilter @TraceID, 13, 0, 4, 500000;

-- Excluir herramientas de monitoreo
EXEC sp_trace_setfilter @TraceID, 10, 0, 7, N'SQL Server Profiler';
EXEC sp_trace_setfilter @TraceID, 10, 0, 7, N'Microsoft SQL Server Management Studio%';

🏦 Aplicación Bancaria: El SP que "Cuelga" la DB

Escenario típico: El equipo de operaciones reporta que el sistema se pone lento todos los días a las 3:00 PM durante el proceso de conciliación.

Estrategia de diagnóstico:

  1. Crear trace filtrado por Duration >= 5 segundos
  2. Activar antes del horario problemático (2:45 PM)
  3. Capturar eventos SP:Completed y SQL:BatchCompleted
  4. Analizar resultados ordenando por Duration DESC
  5. Identificar el SP/query más lento y revisar su plan de ejecución

📊 Alternativa: DMVs sin Trace

Cuando no tienes permisos para crear traces, usa las Dynamic Management Views:

-- TOP 10 consultas más lentas
SELECT TOP 10
    SUBSTRING(st.text, 1, 200) AS Query,
    qs.execution_count AS Ejecuciones,
    qs.total_elapsed_time / 1000 AS TotalMS,
    qs.total_elapsed_time / qs.execution_count / 1000 AS PromedioMS,
    qs.total_logical_reads AS Lecturas
FROM sys.dm_exec_query_stats qs
CROSS APPLY sys.dm_exec_sql_text(qs.sql_handle) st
ORDER BY qs.total_elapsed_time DESC;

-- TOP 10 SPs más ejecutados
SELECT TOP 10
    OBJECT_NAME(ps.object_id) AS SP,
    ps.execution_count AS Ejecuciones,
    ps.total_elapsed_time / 1000 AS TotalMS
FROM sys.dm_exec_procedure_stats ps
WHERE database_id = DB_ID()
ORDER BY ps.total_elapsed_time DESC;
