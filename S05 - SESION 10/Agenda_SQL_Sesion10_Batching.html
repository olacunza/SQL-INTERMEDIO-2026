DECLARE @BatchSize INT = 10000;
DECLARE @RowsAffected INT = 1;

WHILE @RowsAffected > 0
BEGIN
  DELETE TOP (@BatchSize) FROM MiTabla
  WHERE Fecha < @FechaCorte;

  SET @RowsAffected = @@ROWCOUNT;
END

⚡ TRY_CONVERT vs TRY_CAST vs TRY_PARSE

Función Uso Principal Ejemplo
TRY_CONVERT Con estilo de formato TRY_CONVERT(DATE, '2024-01-15', 120)
TRY_CAST Conversión simple TRY_CAST('100' AS INT)
TRY_PARSE Cultura específica TRY_PARSE('15/01/2024' AS DATE USING 'es-ES')

⚠️ Diferencia Clave

  • • CAST/CONVERT normal → ERROR si falla
  • • TRY_* → NULL si falla (sin error)
  • • Ideal para datos importados o usuarios
