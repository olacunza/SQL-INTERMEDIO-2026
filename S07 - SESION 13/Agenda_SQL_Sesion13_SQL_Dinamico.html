⚔️ EXEC vs sp_executesql

❌ EXEC (@sql)

Sin parámetros, vulnerable

'SELECT * FROM T WHERE X = ''' + @Val + ''''

✅ sp_executesql

Parametrizado, seguro

sp_executesql @sql, N'@V INT', @V = @Val

🛡️ SQL Injection - Tipos de Ataque

Tipo Payload Efecto
Bypass Auth ' OR '1'='1 Login sin password
Comment admin'-- Ignora condiciones
Stacked '; DROP TABLE X;-- Ejecuta DDL
UNION ' UNION SELECT... Extrae datos
