📊 Umbrales de Fragmentación

Fragmentación Estado Acción
< 5% ✓ Óptimo No hacer nada
5% - 30% ⚠ Moderada ALTER INDEX ... REORGANIZE
> 30% ✗ Severa ALTER INDEX ... REBUILD

🔄 REORGANIZE

  • ✓ Online siempre
  • ✓ Interrumpible
  • ✓ Bloqueo mínimo
  • ✗ No cambia Fill Factor
  • ✗ No actualiza stats

🔨 REBUILD

  • ✓ Reconstrucción total
  • ✓ Actualiza estadísticas
  • ✓ Cambia Fill Factor
  • ⚠ Puede requerir ONLINE
  • ⚠ Más recursos

📈 TRANSACCIONES_BANCARIAS

INSERTs secuenciales (por fecha). Fill Factor: 95% - mínima fragmentación natural.

💰 CUENTAS

UPDATEs frecuentes de saldo. Fill Factor: 85% - espacio para crecimiento.

👤 CLIENTES

Datos estables, pocas modificaciones. Fill Factor: 95-100% - máxima densidad.

📊 Índices NC

Más susceptibles a page splits. Fill Factor: 80% - margen prudente.
